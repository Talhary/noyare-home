🔧 How the OS Tweaks Work

Noyare optimizes operating system behaviors safely and non-destructively through standard system calls:

  • Windows 11 Context Override: Instantly overrides the bloated modern menus. Noyare maps an empty InprocServer32 key under Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}, and broadcasts a shell message SHChangeNotify(SHCNE_ASSOCCHANGED, SHCNF_IDLIST, null, null) so Explorer reloads the menu configuration instantly without crashing.
  • Window metrics tweak: Scales global scrollbar width values under Control Panel\Desktop\WindowMetrics between -120 to -300 twips (standard is -252 twips).
  • Focus and speed delays: Minimizes mouse-hover delays under MenuShowDelay, keeping interaction thresholds fast. Supports a complete rollback backup.
