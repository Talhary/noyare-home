03 · THE DASHBOARD

A single pane where every signal lives.

Open Noyare, see your machine. A 90-second multi-trace ribbon overlays CPU, RAM, network, and disk. Per-core sparklines breathe at 1.1s. Memory splits into apps / system / cache / free. Drives, interfaces, and DNS sit one click below.

  • Full-bleed live ribbon — four overlaid traces, glow rendered.
  • Per-core grid — every CPU core with its own 30-tick sparkline.
  • Memory segmentation — apps · system · cache · free + swap.
  • Drive health — every mount, every fill rate, every alert.
04 · PROCESSES

Every PID, every binary, every byte.

A sortable, filterable table of every running process — name, PID, CPU, memory, path. Inline mini-bars show CPU load at a glance. Trust evaluation flags unsigned binaries. Drill into child processes; end tasks in a click.

  • Live ticking — CPU and memory update every 1.1s, no flicker.
  • Trust evaluation — every binary scored: trusted · suspect · blocked.
  • Search anywhere — name, path, PID, or process group.
  • Smart sorts — CPU, memory, PID, name, alphabetical, recent.
05 · PORTS

Open sockets, classified at a glance.

Every listening port and every established connection laid out as a grid, each cell color-tagged by exposure. Click any cell to jump to the owning process. UDP and TCP shown side by side; IPv4 and IPv6 unified.

  • Risk classification — SAFE · EXPOSED · SYSTEM, scored locally.
  • Loopback first — separate localhost-only listeners from public.
  • State filtering — LISTENING, ESTABLISHED, TIME_WAIT, CLOSED.
  • Process linkage — jump straight to the binary that owns the port.
06 · NETWORK

See every byte leave your machine.

A passive DNS sniffer streams every outbound lookup in real time — domain, resolved IP, originating process. Active connections list every flow with remote IP, duration, and reverse-resolved hostname. Nothing is sent anywhere; everything is captured locally.

  • Live DNS sniffer — every lookup, with the process that asked.
  • Connection map — local ↔ remote, protocol, duration.
  • Per-interface meters — Wi-Fi, Ethernet, virtual adapters.
  • Domain-level filters — block, log, alert by domain or IP range.
07 · STORAGE

Reclaim the disk, one click.

Two tools in one screen. The Quick Cleaner scans every known cache location — browsers, package managers, build tooling, system temp — and lets you reclaim them in one shot. The Disk Analyzer recurses a folder and ranks children by size with live treemap viz.

  • 12 cache scanners — browsers, npm, pip, yarn, Docker, VSCode…
  • Live tally — running sum updates as you toggle categories.
  • Disk analyzer — sort any folder by size with bar distribution.
  • Safe-by-default — never touches user docs, only known caches.
08 · PROXY INTERCEPT

A pocket-sized Charles Proxy.

A local HTTPS proxy with a beautiful inspector. Capture every request from every binary, break on response, modify headers and body, then send it back. Repeater rebuilds requests with new params. Export the CA in one click — fully self-signed, fully local.

  • HTTP/HTTPS capture — full headers, body, timing, every flow.
  • Break on rules — pause requests matching any predicate.
  • Repeater — replay any captured request with edits.
  • Self-signed CA — export, install, rotate at any moment.
09 · MEMORY CLEANER

Optimize system memory instantly.

Standby memory lists and cached pages can clog your system, leaving less active RAM. Noyare's RAM Cleaner introduces an Intelligent Standby List Cleaner (ISLC) engine to automatically free up caches when memory thresholds are hit, alongside manual working set trimming.

  • ISLC Engine — Auto-purges standby cache based on free RAM limits.
  • Working Set Trimmer — Reclaims active process memory buffers safely.
  • Live Cache Tally — Visualizes RAM consumption across system categories.
  • Low Overhead — Runs in the background without stealing CPU cycles.
10 · STARTUP APPS

Control your boot experience.

Heavy login programs increase startup latency. Noyare lists all registered startup apps in registry keys and startup folders, computes their impact, and lets you disable, delete, or configure custom launch delays so your computer boots instantly.

  • Launch Delays — Postpone heavy boot items to ease initial CPU load.
  • Registry Analyzer — Scans standard and advanced system startup paths.
  • Trust Indicators — Flags unsigned startup binaries automatically.
  • Toggle & Delete — Safely enable, disable, or delete boot tasks.
11 · INSOMNIA MODE

Your machine stays awake, on your terms.

Prevent system sleep or screen display timeout during long renders, downloads, or builds. Set simple continuous overrides or build advanced process-based rules, network transfer limits, and battery safeguard thresholds.

  • Continuous Wake — Prevent screen and sleep cycles indefinitely.
  • Process Watch — Only keep awake while specific processes are running.
  • Battery Threshold — Automatically deactivate below set battery power.
  • Network Guard — Keep awake during active file transfers.
12 · BATTERY DIAGNOSTICS

Precision power telemetry.

Monitor battery wear level, charge cycles, health status, and live discharge rates. Keep track of battery capacity history logs over time and generate a clean Windows battery diagnostics report in one click.

  • Wear Telemetry — Track design capacity vs current full charge capacity.
  • Discharge Rates — Watch energy flow in Watts under different system loads.
  • History Logs — Maintain historic records of battery level and health.
  • Report Generator — Build and export complete HTML diagnostic sheets.
13 · SYSTEM TWEAKS

Personalize and optimize your desktop.

Noyare offers a dashboard of deep operating system tweaks. Shrink or expand scrollbars, configure hover focus timeouts, tweak explorer file display speeds, and disable background telemetry trackers.

  • Scrollbar Customizer — Edit visual scrollbar widths across the OS.
  • Focus Timeouts — Control menu delay reaction speeds under the mouse.
  • Telemetry Block — Toggles to disable background usage logging.
  • Explorer Speedups — Registry-based response timing enhancements.
14 · LOCAL TUNNELS

Expose your ports instantly.

Test webhooks, showcase progress, or route traffic securely. Noyare encapsulates Cloudflare tunnel processes, allowing you to spin up secure public tunnels for local ports and monitor live bandwidth and latency stats.

  • Zero Configuration — Spin up cloudflared instances in a single tap.
  • Public URLs — Mapped to secure HTTPS trycloudflare subdomains.
  • Bandwidth Logs — Live data throughput meters showing Up/Down stats.
  • Process Shield — Native process management wraps the tunnel daemon.
15 · QUICK LOOK

Spacebar file preview, native and fast.

Select a file in Windows Explorer, tap the Spacebar, and instantly see its contents in a translucent, fluid overlay. Works for text files (with live editing and saving), images (with cropping), audio, video, and archive structures.

  • Spacebar Hook — Low-level keyboard hook binds preview to Spacebar.
  • Code Editor — View code with syntax highlighting, edit, and save changes.
  • Image Cropper — Crop, inspect, and export image assets instantly.
  • Archive Reader — List files inside zip and tar.gz files without unpacking.
